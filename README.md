# Ημερολόγιο Τάξης

Ανεξάρτητη, responsive PWA ατζέντα εκπαιδευτικού για κινητό, tablet και υπολογιστή.

Δημοσιευμένη εφαρμογή: <https://elpidakok.github.io/imerologio-taxis/>

## Λειτουργίες

- Ημερήσια άφιξη, αναχώρηση και απουσία ανά μαθητή
- Αιτία ασθένειας, δικαιολόγηση γονέα και σημειώσεις ημέρας
- Καρτέλες μαθητών με κηδεμόνα, τηλέφωνο και μόνιμες σημειώσεις
- Βιβλιοθήκη με δανεισμό και επιστροφή ανά μαθητή
- Ιστορικό παρουσιών ανά ημερομηνία και εκτύπωση
- Εξαγωγή και εισαγωγή αντιγράφου δεδομένων JSON
- Εγκατάσταση ως PWA και offline λειτουργία μετά την πρώτη φόρτωση

## Εκτέλεση

```bash
npm install
npm run dev
```

Production έλεγχοι:

```bash
npm run lint
npm run build
npm run preview
```

## Αποθήκευση δεδομένων

Η τρέχουσα έκδοση είναι offline-first MVP. Τα δεδομένα αποθηκεύονται στο `localStorage` του συγκεκριμένου browser. Η μεταφορά σε άλλη συσκευή γίνεται από τις **Ρυθμίσεις** με εξαγωγή και εισαγωγή αντιγράφου.

Δεν υπάρχει ακόμη λογαριασμός χρήστη, cloud συγχρονισμός ή κρυπτογράφηση. Για χρήση με πραγματικά ευαίσθητα δεδομένα μαθητών σε πολλές συσκευές απαιτείται ασφαλές backend με authentication, δικαιώματα πρόσβασης και πολιτική αντιγράφων ασφαλείας.
